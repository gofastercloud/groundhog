Built for Agents

Hand your coding agent the keys — with guardrails

Groundhog ships an Agent Skill (skills/groundhog/SKILL.md), repo-level AGENTS.md / CLAUDE.md instructions, a structured ./groundhog CLI, and strict local verification gates so agents can install apps and evolve your Mac declaratively without ever leaking personal data.

Prompt

“Install Linear and watchexec, pin Linear to my Dock, and verify everything.”

  1. 1. Load Skill Agent activates skills/groundhog/SKILL.md and checks the public-vs-private decision tree.
  2. 2. Route Cleanly Adds cask "linear-linear" + Dock entry to private custom/; puts universal CLI brew "watchexec" in public homebrew/.Brewfile.
  3. 3. Dry-Run & Apply Previews changes with ./groundhog check --tags "homebrew,dock", then applies via ./groundhog ansible --tags "homebrew,dock".
  4. 4. Gate & Verify Runs strict make verify & ./groundhog verify-custom — zero regressions, zero /Users/ leaks, signed commits only.

Built for Security-Conscious Agentic Coding

Defence in depth without slowing you down

Deny lists alone are polite suggestions. Groundhog puts real OS, hardware, network, and supply-chain boundaries underneath your agents.

🔐

Zero Private Keys on Disk

Secretive keeps SSH auth and Git signing keys non-exportable inside Apple's Secure Enclave, paired with mlkem768x25519-sha256 PQC KEX, ChaCha20-Poly1305 AEAD, and ForwardAgent no.

📦

Hardened agent-box

Pre-baked non-root groundhog-agent-box image (Python, uv, ruff, pytest) that auto-starts OrbStack and mounts only $PWD:/workspace with --network=none, --read-only, and --cap-drop=ALL.

🔑

agent-git & agent-gh

1-hour single-repo GitHub App tokens + a dedicated signing-only SSH key outside ~/.ssh give agents Verified commits on agent/* branches with per-repo autonomous vs human-review rulesets — never touching Secretive.

🤖

groundhog-agency

Vendor-agnostic autonomous dev harness for Claude Code, Antigravity, and Codex: /spec → /next → offline agent-box TDD → fresh-context reviewer → verified PRs, plus zero-flag agency-install --ship.

🌿

Parallel Agents with gwt

gwt add feat/x --sesh creates an isolated Git worktree, copies .worktreeinclude files, and launches a dedicated sesh/tmux session so concurrent agents never collide.

🛡️

Supply-Chain Locks

npmrc ships with ignore-scripts=true, git verifies fsckObjects=true, pip refuses global installs outside uv venvs, and Gitleaks + TruffleHog + OSV-Scanner guard every repo.

⚡

Python CLI & curses TUI

Zero-dependency ./groundhog TUI and non-interactive CLI. Its ansible command avoids Touch ID prompt spam without NOPASSWD via a visudo-checked drop-in staged inside /etc/sudoers.d/, cleaned up with sudo -k on exit.

⏳

7-Day Supply-Chain Cooldowns

uv (exclude-newer), mise (minimum_release_age), and npm (min-release-age + ignore-scripts) wait 7 days before adopting fresh packages, paired with a global Git Gitleaks init template.
