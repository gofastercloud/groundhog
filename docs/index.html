Built for Security-Conscious Agentic Coding

Defence in depth without slowing you down

Deny lists alone are polite suggestions. Groundhog puts real OS, hardware, network, and supply-chain boundaries underneath your agents.

🔐

Zero Private Keys on Disk

Secretive keeps SSH auth and Git signing keys non-exportable inside Apple's Secure Enclave, paired with mlkem768x25519-sha256 PQC KEX, ChaCha20-Poly1305 AEAD, and ForwardAgent no.

📦

Disposable agent-box

Drop into an offline OrbStack container mounting only $PWD:/workspace with --cap-drop=ALL and no-new-privileges — zero host ~/.ssh, ~/.aws, or env leakage.

🌿

Parallel Agents with gwt

gwt add feat/x --sesh creates an isolated Git worktree, copies .worktreeinclude files, and launches a dedicated sesh/tmux session so concurrent agents never collide.

🛡️

Supply-Chain Locks

npmrc ships with ignore-scripts=true, git verifies fsckObjects=true, pip refuses global installs outside uv venvs, and Gitleaks + TruffleHog + OSV-Scanner guard every repo.

⚡

Single-Auth Ansible Helper

./dotfiles.sh ansible solves macOS Touch ID prompt spam without NOPASSWD: a visudo-checked temporary global ticket keeps workers authenticated, then deletes itself and runs sudo -k on exit.

🔑

Scoped Runtime Secrets

API tokens live in ~/.config/private/secrets.env (0600) — never exported in shell profiles. Load them for one command via with-secrets, or encrypt at rest with age.
